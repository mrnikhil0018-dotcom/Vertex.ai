# Vertex.ai Login Preview

This repository contains a simple premium login UI preview.

## Quick Start (Mobile)
Open `mobile-preview.html` directly in your browser.

## Quick Start (Desktop)
Run:

```bash
python3 -m http.server 5500
```

Then open:
- `http://localhost:5500/index.html`
- `http://localhost:5500/preview.html`

- `http://localhost:5500/home.html` (after login/signup)
